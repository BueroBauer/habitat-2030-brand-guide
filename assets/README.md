# Ablage für Brand-Material

Datei in den passenden Ordner legen, `python3 inventory.py` zeigt was erkannt wurde, `python3 build.py` baut es ein.

| Ordner | Inhalt | Formate | Erscheint in |
|---|---|---|---|
| logo/ | Logo-Varianten | SVG (bevorzugt), PNG | Logo, Downloads |
| fonts/ | Markenschrift, Dateiname mit "bold" für Fett | WOFF2, WOFF, TTF, OTF | Typografie, alle Specimen |
| images/ | Bilder für Galerie | SVG, PNG, JPG, WebP, GIF | Galerie |
| photography/ | Fotografie-Beispiele | JPG, PNG, WebP | Fotografie |
| icons/ | Icon-Set | SVG | Iconografie |
| videos/ | Clips | MP4, WebM | Galerie, Intro, Bento |
| gradients/ | Verlauf-Assets | SVG, PNG, JPG | Farbe, Downloads |
| source/ | Originaldateien | AI, PDF, ZIP | Downloads |
| intro/ | Bis 24 Medien für das animierte Intro | Bilder, MP4, WebM | Intro |

Originale bleiben unverändert. Ein leerer Ordner erzeugt eine Lücken-Markierung, keinen Platzhalter.
